# Support

This repository is a **binary release repository**, not the primary Streemrz Dojo support desk.

## Before requesting support

Confirm:

1. You installed Streemrz Dojo from an official release in this repository.
2. Your Windows installation is fully updated.
3. Your microphone, camera and graphics drivers are current.
4. You restarted Streemrz Dojo after changing devices.
5. The problem still occurs on the latest available build.

## Useful diagnostic information

Provide:

- Streemrz Dojo version;
- Windows version and architecture;
- installation type: installed build or development build;
- affected area;
- exact reproduction steps;
- expected result;
- actual result;
- sanitised console or diagnostic output;
- whether the problem persists after restart.

Affected areas may include:

```text
Sign-in
Direct Tegami
Dojo channels
Reactions
Attachments
Voice
Camera
Screen sharing
Soundboard
Installer
Updates
```

## Information you must remove

Do not publish:

- OAuth access tokens;
- passwords;
- cookies;
- `.env` values;
- private message contents;
- private media;
- payment details;
- personal information belonging to another user.

## Security issues

Do not use ordinary support channels for a vulnerability.

Follow [SECURITY.md](SECURITY.md).

## Installer problems

For installer reports, include:

- installer filename;
- installer SHA-256;
- whether Windows displayed SmartScreen or Unknown Publisher;
- whether installation requested administrator elevation;
- whether shortcuts were created;
- whether Streemrz Dojo appears in Apps & Features;
- the exact error text.

## Automatic-update problems

For update reports, include:

- current version;
- target version;
- update status shown in User Settings → Application;
- whether the application was in a call;
- whether download or restart failed;
- sanitised updater logs.

Do not attach the encrypted session file from `%APPDATA%\Streemrz Dojo`.
